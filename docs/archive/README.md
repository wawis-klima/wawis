# Archiwum WAWIS

Pliki historyczne przeniesione z katalogu głównego w wersji 14.50 (porządek po audycie 20.11.2026). Nic nie zostało
usunięte — pełna historia jest w Git.

- `release-results/` — raporty dawnych wydań (`RELEASE-RESULT-<wersja>.md`). Bieżący raport automatyki to
  `RELEASE-RESULT.md` w katalogu głównym.
- `catalogs/` — katalogi EAN Rotenso (CSV) z wersji 8.95–9.02.
- `notes/` — stare instrukcje i notatki (wdrożenie Edge Functions 9.37/9.87, audyt katalogu Rotenso 9.02,
  README techniczne 10.10, wyzwalacz wdrożenia 10.31).

Historyczne pliki SQL są w `supabase/migrations/archive/` (opis w tamtejszym README). Aktywne migracje bazy to wyłącznie
pliki z datą w nazwie w `supabase/migrations/` (np. `20261120180000_…_v1449.sql`).
