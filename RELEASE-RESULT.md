# WAWIS 12.34 — gotowa do wdrożenia

Poprawiono układ pełnej historii wysyłek SMS.

- stałe kolumny: Klient / Telefon / Termin / Cykl / Data wpisu / Status,
- wyrównane wiersze niezależnie od długości nazwiska klienta,
- status nie jest już odsunięty na skraj szerokiego kontenera,
- brak rozszerzania karty historii i niepotrzebnego poziomego przewijania,
- responsywny układ pionowy na węższych ekranach.

Bez zmian logiki wysyłania SMS i bez zmian bazy danych.
